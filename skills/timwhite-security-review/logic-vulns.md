# 业务逻辑与功能漏洞 (Business Logic Flaws)

本文件用于指导 Agent 识别与业务流程相关的安全问题，适用于授权、交易、流程控制和运维管理等通用业务场景。

## 1. 权限与访问控制 (Broken Access Control)

- 水平越权 (IDOR)
- 垂直越权
- 未授权访问
- Webhook / 机器人 / CI/CD 接口是否只靠路径可访问就执行高危逻辑

## 2. 支付与交易逻辑

- 金额是否完全由客户端传入
- 数量 / 金额是否允许负数或溢出
- 余额 / 库存是否缺少并发控制

## 3. 流程绕过

- 是否可以跳过关键步骤
- 验证码 / OTP 是否可复用或仅在客户端校验

## 4. 密码与认证逻辑

- 重置 Token 是否可预测
- 是否允许弱密码

## 5. 管理与运维接口

- 构建 / 部署触发接口是否强认证和授权
- 消息通知接口是否未鉴权就可向内部目标发送消息
- 配置管理接口是否直接暴露
- 缓存 / 键值存储查询接口是否可能泄露敏感键名或数据
