```markdown

### Date
- [YYYY-MM-DD]

- [Why this command run started]

### Starting Artifacts
- [Existing artifacts available at round start]

### Planned Delegated Slices
- [Bounded slices the main session plans to delegate]

### Whole-Repo Reviewer Gate
- [State "not used" by default]
- [If used: why slice-based routing was insufficient]

### Rejected Candidates
- [Candidate summary and rejection reason]

### Net-New Findings
- [New findings added this round]

### Updated Findings
- [Existing findings materially changed, reclassified, or clarified this round]

### Remaining Gaps
- [Coverage gaps or unresolved questions for the next run]

### Notes
- [Delegated slices executed, follow-up details, or round-close observations]
```
