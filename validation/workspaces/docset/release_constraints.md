# Release Constraints

The next release is targeting three customer-facing themes:

1. Better queue visibility for team leads.
2. Cleaner SLA breach explanations in ticket detail pages.
3. Safer self-hosted upgrade instructions.

This release must not introduce:

- a brand new navigation structure
- background job infrastructure changes
- breaking API changes for the existing webhook endpoint

Documentation expectations:

- publish one short launch brief
- publish one operator checklist for upgrades
- call out any residual risk that still exists after rollout
