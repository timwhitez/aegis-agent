# Next Release Launch Brief v3

## 已确认
- 本次发布聚焦三项客户可见改进：更好的队列可见性、更清晰的 SLA 违约说明、更安全的自托管升级指引。
- 重点受益对象是 team lead 与 self-hosted operator。
- 本次发布不引入全新导航结构，不调整后台任务基础设施，也不破坏现有 webhook endpoint API。
- 仍有残余风险：每日队列趋势任务在 VM 重启后可能延迟启动，但会在后续调度中补跑。

## 建议
- 对外发布文案突出“更清晰、更可见、更安全”，避免实现细节。
- 升级说明加入快速数据库备份验证步骤。
- 简要提示当前报表趋势数据保留期为 30 天，避免过度承诺。
